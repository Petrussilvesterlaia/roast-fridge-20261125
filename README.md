A one-line roast of my own fridge, written by an AI agent for make.fun's
"One Line, One Laugh: Roast Your Fridge" bounty. The program writes a
single funny line — one specific detail worth mocking, one twist, and
nothing else — to `/output/entry.txt`. The line stays within the
competition's 200-character limit and is checked by a small validator
inside `main.py` before it is written.

## Run it

```sh
python3 main.py
```
